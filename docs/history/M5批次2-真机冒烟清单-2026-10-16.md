# M5 批次 2 真机手工冒烟清单（一次点完）

> 覆盖：**批次 1 的搜索 UI（12 步）** + **批次 2 的标签面板 W6（8 步）** + **标签重命名 W7（7 步）** + **PR-D 的点击跳转与悬空样式（6 步）**。
> 组织方式：每步写清**先做什么 → 看什么 → 失败长什么样**。失败态也逐条给了"应该看到什么"，看到别的就是缺陷。
> 前置：`pnpm tauri dev`；准备一个 Vault，里面至少有：
> - 两篇互相引用的笔记（`A.md` 含 `[[B]]`，`B.md` 含 `[[A]]` 与一段正文标题 `## 小节`）；
> - 一篇含 `[[不存在的笔记]]`（悬空）与 `![[图片.png]]`（嵌入，图片可放同目录）；
> - 标签：`#项目/alpha/前端`、`#项目/alpha/后端`、`#项目/beta`、`#随笔`（分散在 3 篇以上，其中至少一篇写在 frontmatter 的 `tags:`）；
> - 一篇**没有任何标签**的笔记（验证「未分类」）；以及 3 篇分别写 `#Work`/`#work`/`#WORK` 的笔记（验证大小写去重）。

## B. 标签面板 W6（8 步）
| # | 做什么 | 看什么 | 失败长什么样 |
| --- | --- | --- | --- |
| B1 | 按 `Ctrl/Cmd+Shift+T` | 右侧出现标签面板，**过滤框已聚焦**；顶部有"过滤框 / 排序下拉 / 刷新 / 关闭" | 面板没出现；或出现但过滤框没聚焦 |
| B2 | 看树结构 | `项目` 在根层，其下缩进 `alpha`（再缩进 `前端`/`后端`）与 `beta`；`随笔` 在根层；分支行右侧有「分支」徽标 | 层级没缩进（全平铺）；或只有叶子、没有中间层 |
| B3 | 看每行右侧数字 | 每行数字 = 该标签的引用计数（**行数**口径：`file_tag` 行数，不是笔记篇数）。因 MD-TAG-03 要求「层级标签同时登记自身与全部祖先」，**父行数字天然已含全部子孙** —— 它可能恰好等于各级子标签数字之和（实测出现过 3 = 2 + 1），**相等不是判据** | 出现「父行数字 = 各级子标签数字**逐级相加**」的证据（把子行再加一遍 = 重复计数，PRD §5.3.6.1 明令禁止）。**最干净的对照**：临时加一篇**只写父标签**（如正文只有 `#项目`）的笔记并刷新 → 父行必须 +1、各级子行**不变**；若父行没变、或子行也跟着变，才是缺陷 |
| B4 | 点 `项目/alpha` | 面板下方出现"alpha —— 共 N 篇"与笔记列表；点其中一条能打开该笔记 | 列表空但确实有笔记；或点笔记无反应 |
| B5 | 看列表最末的「未分类」条目 | 排在**最后**，带「未分类」徽标，计数单位是**篇** | 排在中间（应按 §5.3.6.1 恒在最后）；或显示"次" |
| B6 | 点「未分类」 | 列出**没有标签**的笔记 | 报错 / 空列表 |
| B7 | 排序切到「名称」，再在过滤框输入 `alpha`；然后输入 `zzz` | 前者只剩 `项目 → alpha`（**祖先保留**）；后者显示"没有匹配「zzz」的标签" | 过滤后只剩孤立的 `alpha` 行（祖先被裁掉）；或什么都不显示 |
| B8 | 勾选「含子级」 | 笔记列表**不变**（这是**预期**现状），旁边说明写着"祖先登记使该开关无差别（见 D-40②）"；勾选后仍会重新查询 | 面板**声称**开关改变了结果（例如列表变了）—— 那是假装生效 |

| C3 | 点「确认执行」 | "已改写 N 个文件 / M 处标签"；正文与 frontmatter 都改了；`.knowlpad/backup/` 下出现 `tag-rename-*` 目录 | 只改了正文没改 frontmatter（历史缺陷）；或没有备份目录 |

| C6 | **失败态 b（预览过期）**：预览成功后连点两次「确认执行」 | 第二次报"预览已过期（previewId 一次性消费），请重新点击『预览』后再确认"，出现橙色警示，**确认按钮变灰** | 第二次也"成功"（说明 previewId 被复用）；或提示成"改写失败"（让人以为磁盘坏了） |
| C7 | 再点一次「预览」 | 警示消失、确认按钮恢复可用、可正常执行 | 按钮一直灰着（锁死无出路） |

## D. 阅读态扩展语法与点击路由 PR-D（6 步）
| # | 做什么 | 看什么 | 失败长什么样 |
| --- | --- | --- | --- |
| D1 | 打开 `A.md`，切到**阅读**（或分屏），正文写 `[[B]]`、`[[B|别名]]` | 显示为**可点击的链接样式**（蓝色带下划线）；`[[B|别名]]` 显示**别名**；不再是原文 `[[B]]` | 原样显示 `[[B]]`（渲染规则没生效）；或显示了但点不动 |
| D2 | 对已裁决链接做 `Ctrl/Cmd+点击` | 跳到 `B.md`（与反链面板/SearchResults 同一条通路） | 普通单击就跳（阅读时误触）；或 Ctrl+点击无反应 |
| D3 | 看 `[[不存在的笔记]]` | **视觉区分**：灰色 + 虚线下划线 + 尾部 ⚠ | 与正常链接一样（FR-EDITOR-27 未生效） |
| D4 | **单击**该悬空链接（不带修饰键） | 弹出"新建笔记"对话框，名称**已预填** `不存在的笔记.md`；确认后建出该文件并进入编辑态；这一步是**新增能力**（此前无入口） | 单击就跳（无此笔记→报错）；或对话框名称空着（预填没生效） |
| D5 | 在正文写 `#项目/alpha`，切阅读态后**单击**标签 | 标签面板打开**并选中** `项目/alpha`（下方列出它的笔记） | 只是高亮不跳；或打开面板但没选中 |
| D6 | 正文写 `![[图片.png]]`（嵌入） | 显示为**紫色**的嵌入样式（与普通链接区分）；点击行为与普通链接同路。**注意：本轮不渲染图片本身**（FR-EDITOR-29 是 P1，见 D-44 的兄弟项） | 期待它变图片 —— 那是**未实现**而非缺陷；若显示成普通链接颜色则区分失效 |

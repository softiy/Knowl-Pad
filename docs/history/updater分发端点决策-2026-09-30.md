# 自动更新分发端点决策（2026-09-30）

> 本文件是**决策待办与依据记录**，不是真相源。方向确认后再修改 PRD §1.2 / §4.12 与技术方案 §11.5。

## 1. 矛盾

| 来源 | 说法 |
| --- | --- |
| PRD §1.2 | 商业模式：**开源 / 免费（发布至 Gitee Release）** |
| PRD §4.12 + FR-UPDATE-01~14 | 客户端启动时自动检查更新，更新源为 Gitee Release（含 2 项 P0：签名验证、SHA-256 完整性校验） |
| 实际仓库 | GitHub `softiy/Knowl-Pad` 与 Gitee `klincode/knowl-pad` **均为私有** |

**技术后果**：私有仓库的 Release 资产需要认证才能下载，而 Tauri updater 是**匿名 GET**：

- 匿名请求更新清单 → 404（GitHub 对私有仓库匿名访问直接返回 404，已实测：`GET /repos/softiy/Knowl-Pad` 匿名 = 404）；
- 即便拿到清单，安装包与 `.sig` 下载同样被拒；
- **不能**把访问令牌内嵌进客户端：令牌可被提取、会过期，且违反 PRD SEC-05（最小权限）。

> 附注：`tauri-plugin-updater` 支持自定义请求头，因此"内嵌令牌"技术上可行——但**安全上不可接受**，本条仅用于排除该选项。

## 2. 四个可选方案

| 方案 | 做法 | 优点 | 代价 / 风险 | 需改动的文档 |
| --- | --- | --- | --- | --- |
| **A. 专用公开分发仓库** | 新建公开仓库（如 `softiy/knowl-pad-releases`）专门托管 Release 资产；`release.yml` 上传到它；updater endpoint 指向它 | 源码保持私有；资产匿名可下载；改动最小 | 多一个仓库；Release Notes 公开 | PRD §4.12「更新源」措辞；技术方案 §11.5 上传目标 |
| **B. 自建公开静态端点** | 对象存储 / CDN 托管 `latest.json` 与安装包 | 完全自控，可加 CDN | 新增运维面与费用；需自建签名与哈希一致性保证 | PRD §4.12 + 技术方案 §11.5 需新增托管流程 |
| **C. 仓库转公开** | 直接把现有仓库设为公开（源码与历史一起公开） | **零代码改动**；符合 PRD §1.2「开源」的现状表述 | 源码与提交历史全部公开（已扫描：108 个文件无任何凭据/私钥） | PRD 无需改（现状即符合）；仅需确认接受公开 |
| **D. 暂不启用自动更新** | V1.0 只提供手动下载安装 | 零风险、零改动 | FR-UPDATE-01~14（含 2 项 P0）整体推迟；SC-10 场景不成立 | 需从 PRD 移除/推迟 FR-UPDATE 系列，并调整 X 系列排除项 |

## 3. 推荐（待确认）

**先澄清一个前提**：PRD §1.2 已写明「开源 / 免费」。若这仍是目标 → **方案 C** 最省事且与真相源一致；
若希望**源码暂不公开**（例如等 V1.0 完成或涉及商业考虑）→ **方案 A**。

| 若… | 选 | 立即要做的事 |
| --- | --- | --- |
| 确实要开源 | **C** | 把两个仓库设为 public；确认 `docs/history/` 中无敏感内容（已核）；updater 直接指向现有 Release |
| 暂不公开源码 | **A** | 新建公开仓库 `knowl-pad-releases`；`release.yml` 增加 `RELEASE_REPO` 变量并把资产上传到它；`tauri.conf.json` 的 updater endpoint 指向新仓库的 `latest.json` |

**不建议 B**（在 V1.0 阶段新增运维面，收益不足以抵消复杂度）；**D 可作为兜底**，但会让 2 项 P0 需求（签名验证 / 完整性校验）一起失去验证场景，需谨慎。

## 4. 方案 A 的落地清单（确认后执行）

1. 你：创建公开仓库 `softiy/knowl-pad-releases`（只需能用 Release，无需任何代码）；
2. 我：`.github/workflows/release.yml` 的 `gh release create` 目标改到该仓库（用 `GH_TOKEN` + `--repo`）；
3. 我：Gitee 侧同步目标改为对应的公开发布仓库（或 Gitee 私有发行仓库改为公开）；
4. 我：`tauri.conf.json` → `plugins.updater.endpoints = ["https://github.com/softiy/knowl-pad-releases/releases/latest/download/latest.json"]`；
5. 验证：匿名 `curl` 该 URL 返回 200 且 JSON 合法（**M9 前必做**，当前因无 Release 还无法验证）。

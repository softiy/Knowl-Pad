## 3. 工作包拆解（按依赖排序；交付行为**对账基准**，收尾时逐条核对）

### WP1 契约补齐与前端 IPC 骨架
- **目标**：把 M2 需要的命令契约一次性补齐（含 D-10 的置顶命令），前端 IPC 类型同步。
- **权威出处**：PRD §5.3.1/§5.3.2、FR-VAULT-07；技术方案 §8（契约与命名）。
- **交付**：
  1. **`vault_pin { vault_id, pinned }`（D-10 的补齐项，本阶段第一条交付行）** —— 同步 PRD §5.3.1 命令表；置顶列 `vault.pinned` 与列表排序已就绪，仅缺写入入口与 UI；
  2. 文件域命令签名与 TS 类型一次性对齐（`file_tree`/`file_list_dir`/`note_create`/`file_rename`/`file_move`/`file_delete`/`folder_create`/`file_stat`/`file_reveal`/`file_validate_name`）；
  3. 前端 `core/ipc/` 的类型化封装（禁止 feature 直接 `invoke`，红线 FE-04）。
- **验收**：门禁 17（TS ↔ Rust 命令名一致）；`vault_pin` 在 PRD 命令表中有条目。

### WP2 文件系统只读层（树的数据源）
- **目标**：`file_tree` / `file_list_dir` / `file_stat` / `file_validate_name` 真实实现。
- **权威出处**：PRD §5.3.2、FR-FILE-01/02/05/12、FR-STORAGE-04；技术方案 §7.3。
- **交付**：
  1. **单层**子节点返回（禁止全量树，IPC-05 的 4MB 约束）；
  2. 排序：文件夹优先 + 按名称（FR-FILE-02 的 P0 部分）；
  3. 隐藏规则：`.knowlpad/` **永远隐藏**；`.` 开头默认隐藏、可设置开启（FR-FILE-05、AC-FILE-09）；
  4. `.obsidian/`、`.git/` 走 `NEVER_TOUCH_DIRS` 语义（只读遍历也跳过，避免无谓 IO）；
  5. 文件名校验复用 `path_guard::validate_segment`（FR-FILE-12 的三平台并集 + Windows 保留名）；
  6. **修正 `note_read` 返回契约**：由 M0 的裸字符串改为 PRD §5.3.2.1 定义的 `NoteContent`（含 `mtimeMs`，作为编辑器冲突检测基线）——见勘误 **D-11**。
- **验收**：AC-FILE-09；单层返回（禁止整树）；排序与隐藏规则的单元/命令层测试。

### WP3 文件写操作（CRUD 与冲突）
- **目标**：新建笔记/文件夹、重命名、移动、删除（最小软删除）、在文件管理器中显示。
- **权威出处**：PRD §5.3.2、FR-FILE-10/11/13/15/28/30；PRD §4.10（回收站，M7 完整化）。
- **交付**：
  1. `note_create`（含 `on_conflict`）与 `folder_create`（多级一次创建）；
  2. `file_rename` / `file_move`（**不含链接改写**；改写属 M4）：原子 rename + 冲突三选项；
  3. **重名不静默覆盖**（FR-FILE-13）：`overwrite` / `rename_new` / `cancel` 三选项；选覆盖时**先备份原文件**到 `.knowlpad/backup/`（AC-FILE-04 要求）；
  4. `file_delete`：**移入 `.knowlpad/trash/` 的最小软删除**（FR-FILE-30 不做永久删除）；完整回收站流程（清单/还原/清空）属 **M7**；
  5. `file_reveal`：经 Tauri opener 在系统文件管理器中显示。
- **验收**：AC-FILE-03（非法名拒绝且不落盘）、AC-FILE-04（不静默覆盖 + 取消后原文件不变）、AC-FILE-05 的存储侧（重命名后编辑器保存写入新路径）；写入全部走原子协议（R-06）。

### WP4 文件树 UI（虚拟滚动 + 交互）
- **目标**：可用的文件树：展开/折叠、虚拟滚动、右键菜单、折叠状态持久化。
- **权威出处**：PRD FR-FILE-01/06/07/08（AC-FILE-06/08）、技术方案 §7.3（扁平化 + 虚拟滚动）。
- **交付**：

  3. 右键菜单：新建笔记/文件夹、重命名、删除、在文件管理器中显示、复制相对路径（FR-FILE-07 的 P0 子集）；
  4. 文件图标按类型区分（FR-FILE-03，P1，可后置）。

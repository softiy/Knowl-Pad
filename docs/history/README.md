## 收敛说明（2026-09-29）

此前 `docs/` 与 `docs/rev/` 各存一份同名文档，易形成「第二处维护点」并造成版本分叉。现已收敛为单一真相源：

- **唯一真相源**：`docs/Knowl-Pad-PRD.md`（v2.3）、`docs/Knowl-Pad-完整技术方案.md`（v6.3）、`docs/Knowl-Pad-架构图.html`（v2.4）、`docs/AGENTS.md`。
- 原 `docs/rev/` 的权威版本已提升至 `docs/`；该目录已于 **2026-09-30 实际删除**（其修订版快照归档于 `baseline-2026-09-26/`）。
- 修订记录与决策文档迁入本目录；收敛前的基线归档于 `baseline-2026-09-25/`。
- 全仓对 `docs/rev/...` 的引用已改为 `docs/history/...`。

> 基线的 `AGENTS.md` **未归档**：它与当前版本差异极小，且归档的 `AGENTS.md` 会被开发工具当作有效指令加载，易造成指令冲突。
